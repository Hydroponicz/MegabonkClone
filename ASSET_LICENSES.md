# Asset provenance and licenses — Carnage Loop

Audit date: 2026-10-05
Branch audited: `preview` (commit `004beba`). `main` contains the same `index.html`
apart from the balance change in `004beba`, so this report applies to both.
Line numbers refer to `index.html` on `preview` at that commit.

## Method

- Listed every file tracked on every branch (`main`, `preview`,
  `claude/blissful-feynman-ax5vrw`, `vercel/install-vercel-speed-insights-ujpx7u`).
  The only tracked file on any branch is `index.html`.
- Searched `index.html` for external URLs, `data:` URIs, `<img>`, `<audio>`,
  `<link>`, `<script src>`, `@font-face`, `url(...)`, `fetch`, `new Image`,
  `new Audio`, WebGL/shader calls and every image, audio and font file extension.
- Compared the first commit (`ee78eac`, "Add files via upload", by GitHub user
  Hydroponicz) with the current file to separate what was uploaded from what was
  added later. Every later commit up to `004beba` is authored by Claude (Anthropic)
  in a Claude Code session, except the merge commit `7e075ae` (Hydroponicz) and the
  Speed Insights commit `f2b83c1` (Vercel bot, unmerged branch).
- Checked font licenses against Google's official font repository
  (`github.com/google/fonts`, files `ofl/bungee/OFL.txt`, `ofl/chakrapetch/OFL.txt`
  and their `METADATA.pb`). Nothing else was looked up outside the repository.

### Classification key

| Label | Meaning |
|---|---|
| **Procedural** | Drawn or synthesized by code at runtime. No asset file exists. |
| **Procedural · user-provided code** | The code that draws it was in the original upload `ee78eac`. Where it came from before that upload is **unknown**. |
| **Procedural · Claude** | The code that draws it was written by Claude in this project (commits `ba55a37`–`004beba`). |
| **External (runtime download)** | Fetched from a third-party server when the page loads. Not stored in the repository. |
| **Device-provided** | Supplied by the player's operating system or browser. Not shipped with the game. |

Where code was in the upload and Claude later modified it, both are named.

## Summary

- **Asset files in the repository: none.** No image, sprite sheet, texture,
  icon, audio, font, shader, tile-map or JSON file is tracked on any branch.
- **Every image, texture and sound is generated by code** inside `index.html`
  (Canvas 2D drawing and Web Audio synthesis).
- **Two external fonts** (Bungee, Chakra Petch) are downloaded at runtime from
  Google Fonts. Both are SIL Open Font License 1.1 (verified in Google's
  font repository, not in this one).
- **No third-party JavaScript packages or libraries** are in the build on `main`
  or `preview`. There is no `package.json` and no build step; `index.html` is
  served as-is.
- **The provenance of the originally uploaded code is unknown.** It was added by
  the repository owner in one "Add files via upload" commit. This repository
  can't show who wrote it, or whether another tool generated it.
- No `LICENSE` file exists, so no license is declared for the game code itself.

## 7. Replace or resolve before App Store / Google Play submission

Ordered by importance.

1. **Confirm rights to the originally uploaded code.** You, as the person who
   uploaded `ee78eac`, need to confirm where that file came from. If you wrote it,
   record that. If another AI tool generated it, check that tool's output and
   commercial-use terms. If it was adapted from someone else's work, get permission
   or rewrite the affected parts. The affected items are I1, I2, I3, I10, I12,
   I14, I16, I17, I20, I21, U1, A1 and A2 (and the title "Carnage Loop"). Until
   this is resolved, treat those items as **unknown**.
2. **Bundle the fonts instead of loading them from Google.** Store builds should
   work offline and avoid an undisclosed Google network request. Download
   Bungee-Regular.ttf and the Chakra Petch 400/600/700 TTFs, add them under
   e.g. `fonts/`, switch line 5 to local `@font-face` rules, and remove lines 3–5.
   OFL 1.1 allows bundling and commercial use, but you must **include each font's
   `OFL.txt`** (copyright line plus license) with the app, and you may not sell
   the fonts on their own.
3. **Add a credits/licenses screen** in the app (for example under Settings) that
   lists Bungee and Chakra Petch with their OFL copyright notices.
4. **Choose a store name that doesn't reference another game.** Don't use
   "Megabonk" or "Clone" in the app name, listing, bundle ID or screenshots.
   Check "Carnage Loop" against existing app-store titles and trademarks.
5. **Don't ship Vercel Speed Insights in the app build.** It only works on
   Vercel-hosted pages. If you keep any analytics, declare them in the App Store
   privacy label and Google Play Data safety form.
6. **Create the store-only assets that don't exist yet:** app icon (all required
   sizes), adaptive icon foreground/background for Android, splash/launch screen,
   store screenshots and feature graphic. Make them yourself or license them, and
   record their source in this file.
7. **Add a `LICENSE` file** (or an "All rights reserved" notice) declaring the
   project's own code, once item 1 is settled.
8. **Review the Anthropic terms for your account** to confirm your commercial use
   of Claude-written code. Items marked "Procedural · Claude" were written in this
   project's Claude Code sessions.
